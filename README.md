# ModBahasaIndonesiaByHoy

Terjemahan Bahasa Indonesia tidak resmi untuk **Demon Slayer -Kimetsu no Yaiba- The Hinokami Chronicles 2** (Nintendo Switch, Title ID `0100AD80208A8000`).

Mod ini menimpa teks bahasa **English**, jadi game harus dijalankan dalam bahasa English.

## Isi terjemahan

Sekitar 21.400 baris teks sudah diterjemahkan, mencakup:

- menu, opsi, menu jeda, panduan tombol, dan pesan sistem
- dialog mode Cerita
- subtitle suara saat pertarungan
- profil karakter, nama skill, dan tutorial
- teks DLC

Teks yang berupa **gambar** (judul besar, logo bab, tulisan bergaya) tidak ikut diterjemahkan.

## Cara pasang di Switch (Atmosphere CFW)

1. Ekstrak zip. Hasilnya folder `atmosphere`.
2. Salin folder `atmosphere` ke **root SD card** (gabung dengan folder `atmosphere` yang sudah ada).
3. Pastikan bahasa game atau konsol diset ke **English**.
4. Jalankan game lewat CFW.

Tiga file mod akan berada di:

```
SD:/atmosphere/contents/0100AD80208A8000/romfs/APK2/Content/Paks/
  ModBahasaIndonesiaByHoy_P.pak
  ModBahasaIndonesiaByHoy_P.utoc
  ModBahasaIndonesiaByHoy_P.ucas
```

## Cara pasang di emulator

Salin folder `0100AD80208A8000` ke folder mod emulator kamu, sehingga strukturnya menjadi:

```
<folder load emulator>/0100AD80208A8000/ModBahasaIndonesiaByHoy/romfs/APK2/Content/Paks/
  ModBahasaIndonesiaByHoy_P.pak
  ModBahasaIndonesiaByHoy_P.utoc
  ModBahasaIndonesiaByHoy_P.ucas
```

Lokasi folder `load` berbeda tiap emulator. Untuk Eden dan Yuzu: `user/load/`. Untuk Ryujinx: `mods/contents/`. Setelah itu aktifkan mod di Properties → Add-Ons.

## Cara copot

Hapus tiga file `ModBahasaIndonesiaByHoy_P.*` di lokasi di atas.
